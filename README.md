# Beyond IPTV — site

Landing page, privacy policy (TR / EN) and a royalty-free demo playlist for [Beyond IPTV](https://semdin.github.io/beyond-iptv-site/).

- `privacy.html`, `privacy-en.html` — privacy policy
- `demo/demo.m3u` — demo playlist (channels, movies, series) with `demo/epg.xml.gz` TV guide

All demo logos, posters, stills and videos are generated by scripts in the app repository (`store/tools`); fonts: Inter (SIL OFL 1.1).
